# Лента ВК на сайте — инструкция для новичков

Что делает эта штука: раз в сутки сама берёт свежие посты из группы ВК,
сохраняет их и показывает на сайте в ленте. Тебе кодить ничего не нужно.

Сделай шаги по порядку. Каждый шаг — это «нажми вот это, вставь вот это».

---

## Шаг 1. Создать папку на GitHub

GitHub — бесплатный сайт, где хранятся файлы.

1. Зайди на https://github.com и зарегистрируйся (если аккаунта нет).
2. Нажми зелёную кнопку **New** (или значок «+» → New repository).
3. Название: `vk-feed`
4. Поставь переключатель в положение **Public**.
5. Нажми **Create repository**.

## Шаг 2. Загрузить файлы

1. На открывшейся странице нажми ссылку **uploading an existing file**.
2. Распакуй архив `vk-feed-avto.zip` на компьютере.
3. Перетащи в окно браузера **всё содержимое папки `vkauto`**:
   файлы `feed.json`, `seed.json`, `tilda-embed.html`, `README.md`,
   папки `img`, `scripts`, `.github`.
4. Внизу нажми **Commit changes**.

Если папка `.github` не загрузилась (она скрытая), сделай так:
**Add file → Create new file**, в поле имени набери
`.github/workflows/update.yml`, вставь текст из файла `update.yml`
(открой его блокнотом), и нажми **Commit new file**.

## Шаг 3. Получить ключ ВК

Ключ нужен, чтобы сайт мог читать группу ВК.

1. Зайди на https://dev.vk.com и войди в свой аккаунт ВК.
2. Нажми **Мои приложения → Создать приложение**.
3. Название — любое, например `feed-site`.
4. Тип выбери **Standalone**.
5. Открой созданное приложение → вкладка **Настройки**.
6. Найди строку **Сервисный ключ доступа** и нажми «скопировать».
   Ключ начинается на `vk1.a.` и очень длинный.

Ключ не отправляй в чат и никому не показывай. Тот ключ, что ты присылала
раньше, не подходит (это ключ группы), и его лучше отозвать.

## Шаг 4. Сохранить ключ в GitHub

1. Открой свой репозиторий `vk-feed` → вкладка **Settings** (вверху справа).
2. Слева: **Secrets and variables → Actions**.
3. Нажми **New repository secret**.
4. В поле **Name** впиши ровно: `VK_TOKEN`
5. В поле **Secret** вставь скопированный ключ.
6. Нажми **Add secret**.

## Шаг 5. Включить автообновление и проверить

1. Вкладка **Actions** вверху.
2. Если просят подтвердить — нажми зелёную кнопку, что разрешает запуск.
3. Слева выбери **Обновление ленты ВК**.
4. Справа нажми **Run workflow** → ещё раз **Run workflow**.
5. Подожди минуту. Должна появиться зелёная галочка.
   Если красный крестик — пришли мне скриншот этой страницы.

Теперь лента обновляется сама раз в сутки в 09:00 по Москве.
Вручную можно запустить в любой момент тем же способом (шаг 5).

## Шаг 6. Вставить ленту на сайт (Тильда)

1. Открой файл `tilda-embed.html` блокнотом.
2. Найди строку, где написано `https://raw.githubusercontent.com/USER/REPO/main/feed.json`
   и замени `USER` на свой логин GitHub, `REPO` — на `vk-feed`.
   (Или просто пришли мне свой логин GitHub — я сама впишу адрес и пришлю готовый файл.)
3. В Тильде: **Добавить блок → Другое → T123 (HTML-код)**.
4. Нажми на блок → **Контент** → удали всё, что там было → вставь код целиком.
5. **Сохранить** → **Опубликовать**.

Размер кода маленький (около 11 КБ), лимит Тильды не мешает.

---

## Если что-то не работает

- **На сайте написано «Не удалось загрузить ленту».**
  Скопируй адрес из строки `var FEED` в файле и открой его в браузере.
  Должна открыться страница с текстом. Если там «404» — неверный логин или
  название репозитория.
- **В Actions красный крестик.**
  Пришли мне скриншот — я скажу, что исправить.
- **Посты не обновились.**
  Запусти вручную (шаг 5). Обновление по расписанию может прийти с задержкой.

## Что важно знать

- Репозиторий **публичный**: посты и картинки видны всем. Это то же, что и
  так открыто на стене ВК.
- Ключ ВК лежит только в секретах GitHub и в файлы не попадает.
- Лента хранит последние 20 постов. Старые сами пропадают.
- Настройки (сколько постов, качество картинок) меняются в файле
  `.github/workflows/update.yml`, но без необходимости лучше не трогать.
