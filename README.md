# Лента ВК на сайте — инструкция

Что делает эта штука: раз в сутки сама берёт свежие посты из группы ВК
и показывает их на сайте. Ключи, пароли, регистрация приложений — ничего
этого не нужно.

Сделай шаги по порядку. Ничего программировать не надо.

---

## Шаг 1. Создать папку на GitHub

GitHub — бесплатный сайт, где будут храниться файлы ленты.

1. Открой https://github.com и нажми **Sign up** (вверху справа).
2. Введи почту, придумай пароль и имя пользователя.
   **Важно:** имя — латиницей, например `kultura-ao`.
3. Подтверди почту (GitHub пришлёт письмо).

## Шаг 2. Создать репозиторий

1. Нажми зелёную кнопку **New** (или «+» вверху справа → New repository).
2. В поле **Repository name** напиши: `vk-feed`
3. Выбери **Public** — это обязательно, иначе не заработает.
4. Нажми **Create repository**.

## Шаг 3. Загрузить файлы

1. На открывшейся странице найди ссылку **uploading an existing file**
   (мелкий текст в середине страницы).
2. Распакуй архив `vk-feed-avto.zip` на компьютере.
3. Открой папку `vkauto` и выдели **всё** её содержимое:
   `feed.json`, `tilda-embed.html`, `README.md`, `НАЧНИ-ОТСЮДА.txt`
   и папки `img`, `scripts`, `.github`.
4. Перетащи мышкой в окно браузера.
5. Дождись, пока загрузятся (там картинки, около 900 КБ).
6. Внизу нажми зелёную кнопку **Commit changes**.

Проверка: на странице репозитория должны появиться файлы `feed.json`, `img`, `scripts`.

**Если папки `.github` не видно** — она скрытая, начинается с точки.
Включи показ скрытых файлов в проводнике (Windows: вкладка «Вид» → галочка
«Скрытые элементы»). Если всё равно не выходит — скажи мне, дам обходной путь.

## Шаг 4. Включить автообновление

1. Вверху нажми вкладку **Actions**.
2. Если появится кнопка про включение — нажми её (GitHub так спрашивает
   для новых репозиториев).
3. Слева выбери **Обновление ленты**.
4. Справа нажми **Run workflow** → ещё раз **Run workflow**.
5. Подожди минуту и обнови страницу. Должна появиться зелёная галочка.

Если вместо галочки красный крестик — открой его и пришли мне скриншот.
Ничего страшного, это чинится.

Всё. Дальше GitHub сам обновляет ленту каждый день в 09:00 по Москве.

## Шаг 5. Прислать мне ссылку

Скопируй адрес страницы из браузера. Он выглядит так:

```
https://github.com/ТВОЁ_ИМЯ/vk-feed
```

Пришли мне его. Я впишу адрес в код и отдам готовый блок для Тильды —
тебе останется только скопировать и вставить.

## Что будет дальше

Каждый день в 09:00 по Москве GitHub сам:
- забирает новые посты из группы ВК,
- скачивает фотографии,
- обновляет файл ленты.

На сайте ничего делать не надо. Новые посты появляются сами, старые уходят.
Хранятся последние 10 постов.

**Ключ ВК не нужен.** Совсем. Тот ключ, что ты присылала раньше — можно
забыть, и лучше отозвать его в настройках ВК, раз он засветился в переписке.

**Запустить обновление вручную:** вкладка Actions → «Обновление ленты» →
Run workflow. Полезно, если нужен свежий пост прямо сейчас.

## Если что-то пошло не так

**«Не могу найти uploading an existing file»**
Репозиторий уже не пустой. Тогда: **Add file** → **Upload files**.

**«Кнопка Create repository серая»**
Не заполнено имя репозитория. Впиши `vk-feed`.

**В Actions красный крестик**
Открой запуск, пришли скриншот. Обычно это или не загрузилась папка
`.github`, или временный сбой ВК — тогда помогает повторный запуск.

**На сайте написано «Не удалось загрузить ленту»**
Пришли мне ссылку на репозиторий, я проверю адрес в коде.

## Для любопытных: что внутри

```
feed.json                      — сами посты (создаётся автоматически)
img/                           — картинки постов
tilda-embed.html               — код для блока на сайте
scripts/update_feed.py         — сборщик ленты
.github/workflows/update.yml   — расписание «раз в день»
```

Репозиторий публичный: посты и картинки видны всем. Это то же самое, что
и так открыто лежит на стене группы ВК.
